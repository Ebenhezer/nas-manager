Settings

Permissions
When on, users holding the operator role can browse files and view Samba shares and status (read-only). They still cannot upload, delete, create shares or apply the Samba configuration — those actions require explicit write permissions. Defaults to off.
Public upload folder
When on, anyone can upload files to /public/upload (upload-only — there is no public listing) subject to per-uploader quotas. This runtime switch overrides NAS_PUBLIC_UPLOAD_ENABLED once flipped; quotas and cleanup are managed on the Uploads page.
